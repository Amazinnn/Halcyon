# ADR-0017：工作流 v2 重设计（v1.10.4，grill 44 问定稿）

- 状态：已接受（2026-08-08，v1.10.4 修复轮）
- 关联：需求 #51–#57；ADR-0012（M4 工作流引擎 v1）

## 背景

v1.10.3 的工作流（M4 v1）采用 5 类节点 + Vue Flow 连线图。用户 grill 后确认：界面“花里胡哨但不知道功能何在”、画布不占主位；领域模型未对齐——节点职责、系统决定 vs Agent 决定、数据流语义都需重新定义。经 44 问定稿，落为工作流 v2。

## 决策

1. **节点集 8 类**：气泡 / Agent（含填空槽）/ 显示窗口 / 等待 / 分支（多路）/ 专注 / 空闲 / 响铃。原「条件 if」升级为「分支」；「提醒」剔除（语法糖，用 气泡+等待 组合表达，本轮不内置模板）。
2. **Agent 填空槽**：Agent 节点参数增加「填空槽」（字段名 + 2..N 单选候选项，可留空=自由填空）；Agent 回复把答案填入槽，输出槽值供下游引用。分支自动读取上游 Agent 填空槽值作为判断依据（无 Agent 时可选 {{system.*}} 系统字段）。
3. **分支 = 单选多路**：输出口统一为「选项 1..N」（不再保留「是/否」；是/否即二选一特例）；仅单选，不做多选。
4. **允许成环**：去掉创建期环校验，不设执行次数上限；手动取消/删除为逃生口；边显示方向小箭头。
5. **触发头**：工作流属性（触发类型 手动/定时/专注结束/监督告警 + 定时参数 + 守卫 无/专注中/休息中/空闲中），画布顶部徽标展示，创建时配置（默认手动）、可点开编辑。
6. **UI 三栏 + 编辑优先**：窗口默认 6×5（旧 4×3 一次性迁移）；左 150=工作流列表（角色切换、+新建即建、删除确认）；中=画布；右 210=动作库（2 列网格 8 按钮）+ 节点参数。打开即画布、记住上次工作流（settings 持久化 currentWorkflowId）。自动保存（800ms 防抖），无保存按钮、无模板、无快捷键。运行记录移出工作流窗口，改在设置页查看。
7. **引擎扩展**：专注/空闲/响铃通过 provider trait 接入应用层（计时器/声音），引擎保持可脱离 UI 单测；暴露 {{system.focus_state}} 等系统字段引用。

## 后果

- workflow_engine：node kinds 增 focus/idle/ring/branch；validate 不再拒绝环；branch 按槽值/字段路由；agent params 增加 fillSlot；system refs 解析。
- 前端 WorkflowView 全面重构；SettingsPopover 增加运行记录区；MusicView 增加随机播放（第 4 模式，另行记录需求 #58）。
- 布局迁移：workflow 4×3→6×5 一次性。
