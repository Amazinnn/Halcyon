# ADR-0019：Agent 概念定稿与工作流冻结（M5 方向 / M4 收口）

- 状态：已接受（2026-08-08）
- 关联：需求 #64/#65/#66；ADR-0017/0018（工作流 v2 与 v1.10.5 收敛）；M5 路线（#27）

## 背景

v1.10.5 工作流画布收敛后，用户明确「改成一个内置 Agent 的看板，保留当前工作流的设计，但是不再更新」。本 ADR 固化该讨论结论：Agent 概念（M5）与工作流（M4）的边界、冻结范围与一次性数据修复例外。

## 决策

1. **Agent 概念（M5，仅功能需求，细节 TBD）**
   - 每个宠物（Character）↔ 一个 Agent，可切换。
   - 所有 Agent 共享一个对话框；切换 Agent 时对话框上下文被替换。
   - 每个 Agent 过去一天的上下文被存储，但对话框 UI 中对话被清空（存储 ≠ 显示）。
   - 本轮只记录功能需求，不实现；UI/存储细节待 M5 讨论。

2. **工作流降级为日程工具（冻结）**
   - 工作流保留 v1.10.5 设计（7 类节点 / 参数卡片化 / 零变量 / Agent=唯一输出通道），不再加功能、不再重设计。
   - 可绑定/不绑定 Agent：不绑定 = 完全机械化的系统工作流（自动运行的日程安排表）；绑定 = 该 Agent 的日程安排表，在特定时机告诉 Agent 做什么；不是 Agent 本身。
   - 否决项：Agent 出口+动作双通道、槽值自动锁定可解锁、显示窗口开/关节点、重命名「发送给 Agent」→「Agent」等。

3. **冻结边界 = 修完三样后冻结**
   - ① 存档角色绑定（内容丢失根因：character_id='' 孤儿 + characters_list 静默空）
   - ② 连线箭头不显示（手写 SVG marker 未渲染 → Vue Flow 原生 MarkerType.ArrowClosed）
   - ③ 数字框 spinner（Web 默认上下箭头 → CSS 全局隐藏）

4. **一次性孤儿数据找回（例外）**
   - 启动 `repair_orphan_workflows()` 把 `character_id=''` 的历史工作流挂回默认角色。
   - 这是用户明确选择的一次性数据找回，不构成向后兼容层（#62 全局准则仍有效：不兼容旧结构直接删）。

## 影响

- M4 工作流不再演进；M5 以「Agent 看板」为方向另行讨论。
- 后续新需求若触及工作流语义，一律先与用户确认是否属于「冻结边界内」。
