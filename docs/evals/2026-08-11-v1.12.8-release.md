## 行为契约

1. 视图托盘的圆按钮、菜单收起和 chat/stats/music/workflow 恢复共用一个未完成动作状态。原生 `restore` 未返回前不得发起第二次可见性操作；后端并发请求必须明确失败，不能排队堆积。
2. 保持既有契约：无空槽不恢复、可见浮窗不重叠、显示/定位不激活窗口。
3. 聊天输入是单行真实编辑序列：Skill Token 内嵌于文字，可按当前光标插入并连续叠加；相邻 Backspace/Delete 仅删除一个完整 Token；普通文字、选区与粘贴仍按浏览器编辑行为处理。
4. 发送文本严格等于编辑器的可见顺序，例如 `$focus-cli  $readme  查询状态`。Skill 不是独立消息；空正文不得发送；Focus 不读取、注入或拼接 `SKILL.md`。
