# v1.12.10 Float Geometry Eval

Date: 2026-08-11
Requirement: #102

## Scope

This release unifies the floating-window visible client geometry used for grid
preview, snap selection, and final placement. It does not change the accepted
native caption handling, acrylic, rounded corners, window size, topmost path,
or view tray.
